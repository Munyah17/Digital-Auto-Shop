Super Admin — Hero Slides

Manage up to 10 homepage banner slides. A slide only appears on the site when it's active and has a banner assigned.

Banner field: paste an image URL (e.g. https://…/banner.jpg) or pick a gradient preset (gradient-blue, gradient-cyan, gradient-indigo, gradient-sky). Leave empty to hide the slide completely. Changes save automatically to this browser — in production this panel talks to the admin API (/api/admin/slides).
